# SHA-256

## 1. 概述

- **类型**: 密码散列(哈希)函数,256-bit 输出
- **标准**: FIPS 180-4,NIST,SHA-2 家族
- **生产可用性**: ✅ **安全**,广泛用于 TLS、签名、区块链、口令派生(PBKDF2)等

SHA-256 是 SHA-2 系列中最常用的成员,输出 256-bit(32 字节),是当前密码学事实上的默认哈希标准之一。

## 2. 算法原理

基于 **Merkle–Damgård** 结构,使用 64 轮压缩函数:
- 分组: 512-bit(64 字节)
- 输出: 256-bit(8 × 32-bit 状态)
- 消息调度: 将 16 个字扩展为 64 个字

**初始常量 H0..H7** (前 8 个素数的平方根小数部分)
```
6a09e667 bb67ae85 3c6ef372 a54ff53a
510e527f 9b05688c 1f83d9ab 5be0cd19
```

**64 个轮常量 K[0..63]** (前 64 个素数的立方根小数部分)

**每轮使用逻辑函数**
```
Σ0(x) = ROTR2(x) ^ ROTR13(x) ^ ROTR22(x)
Σ1(x) = ROTR6(x) ^ ROTR11(x) ^ ROTR25(x)
σ0(x) = ROTR7(x) ^ ROTR18(x) ^ SHR3(x)
σ1(x) = ROTR17(x) ^ ROTR19(x) ^ SHR10(x)

Ch(e,f,g) = (e & f) ^ (~e & g)
Maj(a,b,c) = (a & b) ^ (a & c) ^ (b & c)
```

## 3. 算法流程

1. **填充**: 补 `0x80` + 零,使长度 ≡ 448 mod 512,末尾 64-bit 存 bit 长
2. 初始化 8 个 32-bit 状态 `H0..H7`
3. 每 512-bit 块:
   - 复制 `W[0..15]`(大端)
   - 用 `σ0/σ1` 扩展为 `W[16..63]`
   - 8 个变量 + 64 轮压缩
   - 累加回 `H0..H7`
4. 输出 `H0..H7` 大端拼接 → 256-bit / 64 hex

## 4. 安全性说明

- SHA-256 是当前**事实上的默认哈希**,广泛使用且未见已公开的碰撞
- 使用在 TLS 1.3 / 数字证书 / 密码派生(PBKDF2) 等场景
- 对于口令存储,建议结合 HMAC 或 KDF (如 PBKDF2-HMAC-SHA256)
- **结论**: 可用于完整性、签名、一般哈希

## 8. 最小可运行示例

```c
#include "sha256.h"
#include <stdio.h>
int main(void) {
    const char *msg = "abc";
    BYTE digest[32];
    SHA256_CTX ctx;
    sha256_init(&ctx);
    sha256_update(&ctx, (const BYTE*)msg, strlen(msg));
    sha256_final(&ctx, digest);
    for(int i=0;i<32;i++) printf("%02x",digest[i]);
    printf("\n");
    return 0;
}
```

```bash
python python/simple/sha256.py "abc"
```
